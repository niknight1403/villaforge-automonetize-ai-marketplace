# AI-Marketplace

## Overview
Autonomous AI-Marketplace for generating, testing, and optimizing AI services.

## Setup
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Run tests: `npm test`

## API Documentation
Interactive documentation is available via Redocly using `docs/openapi.yaml`.

## CI/CD
GitHub Actions pipeline handles automated testing and deployment to Kubernetes.

## Scaling
Horizontal Pod Autoscaling (HPA) is configured for high-demand AI service generation.
